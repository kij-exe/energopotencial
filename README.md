# График энергопотенциала

Калькулятор графика энергопотенциала по дате рождения: график «Жизнь» (по годам) и график «Год» (по месяцам), с периодами «ноль в нуле».

Сайт: https://kij-exe.github.io/energopotencial/

Ссылка на конкретную дату: `https://kij-exe.github.io/energopotencial/#25.02.1960`

Весь сайт — один файл `index.html`, без сборки и зависимостей.
